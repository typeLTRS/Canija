# Canija
  ![Canija](specimen/images/canija-cover.jpg)

**Canija - Una mendiga display, a variable typefaces — On a bold journey.**
  Canija is a typeface project developed around the exploration of contrasting forms, variable axes and expressive display settings.
  Its forms move between angular and reversed structures, creating a system designed to shift, adapt and transform across different typographic contexts.

## About
   Canija is a display typeface family developed as an exploration of variable typography and expressive letterforms.
   The family is built around two variable axes — Angular and Reversa — allowing the forms to move across different degrees of transformation.
   Designed to be flexible and experimental, Canija explores how a typeface can behave as a system rather than a fixed set of styles.

## Features
   - Variable typeface family
   - 2 variable axes: Angular + Reversa
   - 7 weights
   - 21 fonts
   - 446 glyphs
   - Support for 210 languages
   - Small caps
   - Ligatures
   - Oldstyle numerals
   - Stylistic sets
   - Contextual alternates
   - Fractions
